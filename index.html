🎯 Tujuan

Mahasiswa mampu menggunakan Substitution Variable sesuai kebutuhan dalam perintah SQL.

1. Definisi

Substitution variable (variabel substitusi) menyimpan sementara nilai yang di-inputkan pengguna. Ini fitur Oracle SQL Developer yang memungkinkan nilai dimasukkan secara dinamis ke dalam perintah SQL/PL-SQL: query “menunggu” input dulu sebelum dijalankan.

Variabel diidentifikasi dengan karakter & di depan namanya, misalnya &gaji, &bag.

SELECT employee_id, last_name, salary, department_id
FROM employees
WHERE employee_id = &id_karyawan;   -- Oracle bertanya: "Enter value for id_karyawan:" → 101
Analogi: query biasa itu seperti formulir yang sudah terisi. Query dengan & adalah formulir dengan kolom kosong yang diisi tiap kali dipakai.

2. Kapan dipakai?

Kondisi nyataPenjelasan
Laporan dinamisDBA membuat laporan dengan parameter input (tanggal, ID, rentang nilai).
Skrip otomatisasi DBASkrip yang sama untuk berbagai departemen/schema tanpa edit manual.
Testing query cepatMenguji query dengan banyak nilai input tanpa mengubah SQL utama.
Migrasi / maintenanceSkrip yang butuh input seperti nama tabel atau schema yang berbeda-beda.

Mengapa diperlukan? (contoh E-Commerce)

🛒 Pelanggan mencari produk: satu query, nama produk berbeda tiap pencarian.
📦 Admin melihat pesanan per periode: satu script, hanya tanggal yang diganti.
👤 Profil karyawan/pelanggan: satu template, jutaan kemungkinan hasil berdasarkan ID.

Variabel juga bisa dipakai bersama JOIN (mis. WHERE d.department_id = &dept_id) dan subquery. Coba semuanya di tab Simulasi, Lab, dan Latihan.

4. Tambahan: && dan DEFINE

Materi slide memakai single ampersand (&): Oracle bertanya setiap kali variabel muncul. Sebagai pengayaan, &&var bertanya sekali lalu nilainya disimpan selama sesi.

SELECT last_name, &&kolom FROM employees ORDER BY &kolom;  -- kolom diminta sekali
DEFINE gaji = 5000      -- set nilai manual (tanpa ditanya)
UNDEFINE gaji           -- hapus variabel

5. Tips & jebakan umum

• Lupa kutip pada teks: job_id = &jab_kerja lalu mengisi IT_PROG → error invalid identifier.
• Nilai teks case-sensitive: it_prog tidak sama dengan IT_PROG.
• Nama variabel jangan memakai spasi; gunakan _.
• Ada karakter & sungguhan di data? Gunakan SET DEFINE OFF.
• Input angka harus angka; isi “abc” pada &gaji menimbulkan error.
